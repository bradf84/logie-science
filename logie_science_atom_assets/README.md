# Logie Science Atom Asset Pack

A refreshed brand and website asset pack for **Logie Science**.

## Concept

A dark-blue atom logo with colourful science energy. The audience is kids around 10 years old who are interested in experiments and learning how things work.

## Included

- `logo-full-atom.svg` — full logo with atom and wordmark
- `icon-atom.svg` — square atom icon
- `animated-atom-logo.svg` — animated SVG atom logo
- `hero-atom-science.svg` — hero graphic for the homepage
- `experiment-instructions-graphic.svg` — graphic for experiment instructions
- `how-it-works-card.svg` — graphic for science explanation sections
- `brand.json` — brand colours, fonts and tone
- `tokens-and-animations.css` — CSS variables and animation helpers
- `kiro-build-prompt.md` — prompt to paste into Kiro CLI
- `preview.html` — quick local preview of the assets

## Animation notes

The animated SVG and CSS respect `prefers-reduced-motion`, so users who prefer less animation will not get constant movement.

- Home
