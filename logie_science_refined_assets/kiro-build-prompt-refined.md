# Kiro CLI Build Prompt: Logie Science refined version

Build a polished, kid-friendly science website called **Logie Science**.

This version must avoid the previous bad layout where the atom covered the text and buttons.

## Non-negotiable layout rule

The homepage hero must be a clean two-column layout:

- Left: headline, subtitle, buttons
- Right: atom illustration
- No overlapping
- No decorative blob covering text
- No image covering buttons
- Mobile stacks vertically

## Brand

Primary logo concept:
A dark-blue atom with colourful orbit rings.

Audience:
Kids around 10 years old who are interested in science experiments.

Purpose:
The site contains kid-friendly science experiment instructions and explains how each experiment works.

## Assets

Use:
- `logo-full-refined.svg`
- `icon-atom-refined.svg`
- `animated-atom-refined.svg`
- `hero-atom-illustration-refined.svg`
- `layout-safe-tokens.css`
- `brand.json`

## Pages

Create:
- Home
- Experiments
- How It Works
- Facts
- About

## Home page

Hero headline:
`Ask. Try. Notice. Explain.`

Hero subtitle:
`Kid-friendly science experiments with clear steps and simple explanations of how they work.`

Buttons:
- `Start exploring`
- `See experiments`

Sections:
1. Featured experiments
2. How Logie Science works
3. Science fact of the day
4. Safety reminder

## Experiments page

Create cards and detail pages for:
- Balloon Rocket
- Volcano Fizz
- Floating Egg
- Paper Bridge Challenge
- Shadow Tracker
- Dancing Raisins

Each experiment includes:
- Title
- Description
- Difficulty
- Time needed
- Adult help needed
- Materials
- Steps
- What to notice
- How it works
- Safety note

## How It Works page

Explain:
- Reactions
- Forces
- Gravity
- Air pressure
- Density
- Light and shadows

Use plain language suitable for a 10-year-old.

## Technical stack

- Vite
- React
- TypeScript
- CSS modules or plain CSS
- No backend

## Quality bar

The result should look like a real, polished website, not a quick demo.

Use:
- Large readable headings
- Strong spacing
- Rounded cards
- Dark-blue visual identity
- Colourful but controlled accents
- Clear mobile layout
- Accessible contrast
- Semantic HTML

Run the build and fix all errors.
